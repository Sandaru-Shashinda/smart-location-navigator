Functional Requirements
1. User Access
User can sign up with email
2. Location Handling
The system shall capture the user’s real-time GPS location
The system shall update user location at regular intervals
The system shall allow users to enter a destination
3. Traffic Detection
The system shall collect user speed and location data
The system shall calculate the average speed for each road segment
The system shall classify traffic levels as low, medium, or high
The system shall update traffic conditions in real time
4. Route Optimization
The system shall generate optimal routes based on current traffic conditions
The system shall use routing algorithms
The system shall provide alternative routes where available
The system shall automatically update routes when traffic conditions change
5. Fairness-Aware Routing
The system shall monitor the number of users on each route
The system shall estimate road capacity
The system shall distribute users across different routes to avoid congestion
The system shall prevent overloading a single road

6. Alert & Notification System
The system shall send real-time alerts to users
Includes:
Traffic congestion alerts
Weather hazard alerts
Driver fatigue alerts
7. Weather Hazard Detection
The system shall retrieve weather data from a weather API
The system shall detect hazardous weather conditions
The system shall notify users about unsafe road conditions
8. Driver Fatigue Detection
The system shall track continuous driving duration
The system shall detect lack of rest periods
The system shall notify users to take breaks
9. Map Visualization
The system shall display routes on a map interface
The system shall show traffic conditions using visual indicators (colors)
The system shall update map information dynamically
10. User Feedback & Reporting
The system shall allow users to report traffic incidents
The system shall process user-reported data
The system shall incorporate feedback into traffic updates
